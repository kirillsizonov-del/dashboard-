# Quadcode AI · Content Dashboard

Командный дашборд для рассылки и контента: задачи, статусы каналов (Telegram, Instagram, Facebook, Threads), списки целей и аналитика действий.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Что внутри

| Раздел | Что делает |
|---|---|
| Обзор | Блоки по порядку: что делать сейчас, где мы по каналам, как идём к цели недели, последние действия |
| Задачи | Доска из трёх колонок с перетаскиванием, фильтры по каналу и исполнителю, вставка списка задач из чата |
| Каналы | Статус, аккаунт, дневная цель и заметки по каналу. Список чатов или аккаунтов с галочками, этапами воронки и повторными касаниями. Импорт базы из файла и выгрузка в CSV |
| Документы | Офферы, инструкции и выгрузки командой. Загрузка .md, .txt, .csv, отчёт за неделю, выгрузка базы, задач и всех документов |
| Аналитика | Действия по дням и каналам, календарь активности, воронка, вклад участников, активность по часам, поток задач |

Быстрый ввод понимает метки в тексте: `#тг #инст #фб #тредс`, `@имя`, `!!` для срочных, `сегодня`, `завтра`, `12.10`.

Каждая отметка, задача и смена этапа пишется в журнал действий. Вся аналитика считается по журналу.

## Данные

Данные лежат в общей базе Supabase (проект dashboardDD), изменения сразу видны всем, у кого открыт дашборд. Адрес базы и публичный ключ вшиты в `src/lib/config.ts`, поэтому ничего настраивать не нужно. Переменные из `.env.example` их переопределяют.

Таблица создаётся скриптом `supabase/schema.sql`, его нужно выполнить один раз в SQL Editor.

Стартовые данные лежат в `src/lib/seed.ts` и загружаются один раз, когда база пустая.

В схеме открыт доступ без входа: читать и менять данные может любой, у кого есть ссылка на дашборд. Перед публичным запуском добавьте авторизацию и замените правила в `schema.sql`.

## Импорт базы

На странице канала кнопка «Импорт базы» принимает CSV из Google Таблиц и Excel, TXT, JSON, выгрузки чатов или просто вставленный текст. Канал определяется по ссылке: t.me, instagram.com, facebook.com, threads.net. Записи без ссылки уходят в выбранный канал. Повторы внутри файла и уже добавленные записи пропускаются.

В CSV распознаются колонки «Ссылка», «Название», «Заметка» или «Ниша», «Оффер», «Приоритет». Выгрузка базы в CSV имеет тот же формат, поэтому её можно загрузить обратно.

## Документы

Документы хранятся текстом в той же базе Supabase, до 900 КБ на документ. Раз в неделю при первом открытии дашборда сам сохраняется отчёт за прошлую неделю.

## Деплой на Vercel

```bash
vercel
```

Проект на Vercel подключён к репозиторию и собирается сам после каждого пуша в `main`.

## Структура

```
src/app/            страницы: обзор, задачи, каналы, документы, аналитика
src/components/     оболочка, графики, задачи, общие элементы
src/lib/store.ts    состояние и все действия
src/lib/backend-*   хранилища: localStorage и Supabase
src/lib/analytics.ts расчёты для графиков
src/lib/parse.ts    разбор быстрого ввода задач
src/lib/importer.ts импорт базы из файлов и текста
src/lib/exporter.ts выгрузки CSV и отчёты
src/lib/seed.ts     стартовые данные
```
